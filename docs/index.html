agent-x402

Pay per API call in USDC on Base — with a spend policy a prompt injection cannot bypass.

x402 turns a 402 into a signed USDC transfer, which means an agent can buy inference without an account. It also means an agent can spend money. This is the client that pays, and the policy that decides whether it may.

How it works

  1. Request the endpoint: a 402 comes back with the price, the network and the payee.
  2. Check the policy: caps, allow-list and blocked contracts are evaluated before signing.
  3. Sign the transfer with EIP-3009 and retry with the payment attached.
  4. Record the spend so the daily budget stays honest.
